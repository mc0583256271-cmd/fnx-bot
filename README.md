# בוט הפניקס - עוזר שירות לקוחות מבוסס RAG

בוט שעונה על שאלות לקוחות **רק** מתוך המידע שבאתר [fnx.co.il](https://www.fnx.co.il), עם קישור למקור בכל תשובה.

## מבנה הפרויקט
```
fnx-bot/
├── ingest/   "הכנת הספר" - איסוף, ניקוי וחיתוך המידע מהאתר
├── core/     "המוח" - חיפוש, זיהוי שאלות גבול, ותשובה עם מקור
├── eval/     בדיקות איכות על שאלות אמיתיות
├── data/     המידע שנאסף מהאתר
└── app.py    הממשק (הצ'אט)
```
